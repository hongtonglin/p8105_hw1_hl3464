Make a scatterplot of `flipper_length_mm` (y) vs `bill_length_mm` (x)

``` r
ggplot(
  penguins,
  aes(
    y = flipper_length_mm,
    x = bill_length_mm,
    color = species
  )) +
  labs(
    x = "Bill Length (mm)",
    y = "Flipper Length (mm)",
    color = "Species"
  )+ 
  geom_point()  
```
